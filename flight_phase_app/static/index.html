💡 Instructions & Keyboard Shortcuts

Workflow:

  1. Select Aircraft: Choose any aircraft from the dropdown or search by hex ID.
  2. Select Sessions: All sessions of the aircraft are selected by default. Toggle checkboxes to isolate or compare sessions.
  3. Animate & Inspect: Hit Play or drag the scrubber. Watch the aircraft traverse its path with synchronized altitude and phase ribbons.
  4. Manual Tagging: Click and drag on the timeline (or use `[` and `]`) to specify start/end time. Select a phase and click Save Manual Tag.
  5. Refine Heuristics: Open Refinement & Report to see the agreement matrix and suggestions for tuning thresholds in 02-Preprocessing/flight_phase.py.

Keyboard Shortcuts:

  • Space : Play / Pause animation
  • ← / → : Step 5s backward / forward
  • [ : Set tag start time to current playhead
  • ] : Set tag end time to current playhead
  • Esc : Close modals
